# ROZAK.DEV

Portofolio multi-page statis menggunakan HTML, CSS, dan JavaScript.

## Menjalankan lokal
Buka `index.html` atau gunakan VS Code Live Server. Alternatif: `python -m http.server 8000` lalu buka `http://localhost:8000`.

## Deploy GitHub Pages
1. Buat repository GitHub.
2. Unggah seluruh isi folder ini ke root repository.
3. Buka Settings → Pages.
4. Pilih Deploy from a branch, branch `main`, folder `/ (root)`, lalu Save.

## Wajib disesuaikan sebelum publikasi
- Ganti placeholder foto di `index.html` dengan foto yang memang ingin dipublikasikan.
- Ganti konten contoh di `projects.html` dan `project-detail.html` dengan project asli.
- Tambahkan sertifikat asli di `achievements.html`.
- Ganti `YOUR_PUBLIC_PORTFOLIO_EMAIL` pada action form di `contact.html` dengan email khusus portofolio yang disetujui orang tua/wali. FormSubmit memerlukan aktivasi pertama.
- Perbarui usia jika perlu. Usia 14 tahun adalah informasi awal, bukan penghitung otomatis.
- Jangan publikasikan nomor pribadi, data perusahaan, atau informasi sensitif tanpa izin.

## Struktur
Halaman: index, about, skills, projects, achievements, experience, contact. CSS di `css/style.css`, JavaScript di `js/main.js`.

Project jammer hanya disebut sebagai eksperimen keamanan jaringan yang aman; jangan menambahkan fungsi pengganggu jaringan.
